# Ocean Properties - Manual de Identidad para IA

Este documento es la referencia oficial para Claude, Cursor y otros LLMs.

## 1. Paleta de Colores
- **Negro Principal:** `#000000` (Uso para texto y logos sobre blanco)
- **Blanco Principal:** `#FFFFFF` (Uso para fondos y logos invertidos)

## 2. Logos: solo el sistema Grégoire

Grégoire es el único sistema de identidad vigente de Ocean Properties. Los recursos anteriores están retirados y no están autorizados para interfaces, facturas, PDFs, correos, documentos, materiales comerciales ni nuevos diseños. Su existencia en un historial o en una URL accesible no autoriza su uso.

- Archivos vigentes: `logos/logotype-*`, `logos/mark-only-*` y `logos/type-only-*` (negro, blanco y full color).
- Inventario canónico con todos los enlaces: `docs/brand/IDENTIDAD_VIGENTE_GREGOIRE.md` en `oceanproperties-hue/ocean-properties-pwa`.
- Retirados, aunque sigan en esta carpeta: `logo-horizontal-*.png`, `logo-location-*.png`, `logotype-white.png` y `symbol-*.png`. No se usan ni como alternativa.
- Si falta un archivo Grégoire, se informa de la ausencia; no se sustituye por uno retirado.
